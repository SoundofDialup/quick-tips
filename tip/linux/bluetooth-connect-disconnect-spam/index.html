Fix the bluetooth connect/disconnect spam

Use bluetoothctl

$ bluetoothctl

$ power on

If the agent wasn't automatically registered when starting bluetoothctl: 

$ agent on

$ default-agent

$ scan on

If it doesn't automatically pair with the device (use device's MAC address): 

$ pair 00:11:22:33:44:55

$ trust 00:11:22:33:44:55

$ connect 00:11:22:33:44:55
